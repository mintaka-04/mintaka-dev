## 한 일

### Windows 환경에서 서비스 실행해보기

- 원인: 일부 패키지가 wheel 없이 소스 빌드 시도, Windows에 컴파일러 미설치
- `--prefer-binary` 옵션 또는 Visual Studio Build Tools 설치로 해결 가능
- 근본 해결책으로 Docker 도입 검토

## 배운 것
- CloudWatch Metric Filter는 로그 텍스트를 숫자로 변환하는 중간 다리 역할 — 알람은 숫자(지표)에만 걸 수 있음
- `?term` 은 OR 조건, `term` (공백 구분) 은 AND 조건
- CloudWatch 필터 패턴은 대소문자 구분함
- Mac은 Xcode CLT에 clang 기본 포함, Windows는 컴파일러 별도 설치 필요
- Docker는 코드뿐 아니라 실행 환경 자체를 패키징 — OS 차이를 근본적으로 제거
