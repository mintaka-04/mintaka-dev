## 1. 초기 문제: 로지텍 플로우

### 증상
- 파일 복사 후 `.pending` 확장자가 붙음
- 작은 파일(1KB)도 전송이 완료되지 않음

### 원인
- 네트워크 연결 불안정
- Logi Options+ 애플리케이션 동기화 실패

### 해결방안
SMB 네트워크 파일 공유로 전환

## 2. SMB 파일 공유 설정

### 2.1 macOS 설정

#### 기본 설정
1. **시스템 설정** → **일반** → **공유**
2. **파일 공유** 활성화
3. **옵션** 버튼 클릭
4. **SMB를 사용하여 파일 및 폴더 공유** 체크

#### 사용자 계정 설정
1. 옵션 창에서 공유할 사용자 계정 체크
2. SMB 암호 설정 (macOS 로그인 암호와 동일하거나 별도 설정)

#### 공유 폴더 설정
1. 공유할 폴더 선택 (기본: Public 폴더)
2. 사용자별 권한 설정:
   - **읽기 전용**: 파일 조회만 가능
   - **읽기 및 쓰기**: 파일 생성/수정/삭제 가능

#### IP 주소 확인
터미널에서 내부 IP 확인:
```bash
ipconfig getifaddr en0
```
또는 **시스템 설정** → **네트워크** → **세부사항**

### 2.2 Windows 설정

#### 네트워크 프로필 설정
1. **설정** → **네트워크 및 인터넷**
2. 연결된 Wi-Fi 속성에서 **프라이빗(개인) 네트워크**로 설정

#### 파일 공유 활성화
1. **제어판** → **네트워크 및 공유 센터**
2. **고급 공유 설정 변경**
3. **프라이빗** 네트워크 섹션:
   - ✅ 네트워크 검색 켜기
   - ✅ 파일 및 프린터 공유 켜기

#### macOS 연결
파일 탐색기 주소창에 입력:
```
\\macOS_IP_주소
```
예: `\\192.168.0.100`

## 3. 연결 문제 해결

### 3.1 자격 증명 오류

#### 문제
"사용자 이름 또는 암호가 틀립니다" 오류

#### 원인
macOS 표시 이름과 실제 계정 이름이 다름

#### 해결
macOS 터미널에서 실제 계정 이름 확인:
```bash
whoami
```

Windows 연결 시 **실제 계정 이름** 사용
- ❌ 표시 이름 (예: "구름")
- ✅ 계정 이름 (예: "goorm")

### 3.2 연결 초기화

Windows 명령 프롬프트:
```cmd
net use \\macOS_IP_주소 /delete
```
이후 재연결

### 3.3 방화벽 확인

macOS: **시스템 설정** → **네트워크** → **방화벽**
- 파일 공유 차단되지 않았는지 확인

## 4. 권한 문제 해결

### 4.1 증상
- 파일/폴더 조회는 가능
- 파일 생성/수정/삭제 시 "권한이 필요합니다" 오류

### 4.2 SMB 공유 권한 설정

macOS **시스템 설정** → **공유** → **파일 공유**:
1. 공유 폴더 선택
2. 사용자 권한을 **읽기 및 쓰기**로 변경
3. 필요시 "모두" 사용자도 **읽기 및 쓰기**로 설정

### 4.3 파일 시스템 권한 설정

#### Finder에서 설정
1. 공유 폴더 우클릭 → **정보 가져오기**
2. **공유 및 권한** 섹션
3. 🔒 자물쇠 아이콘 클릭 (관리자 암호 입력)
4. 사용자/그룹 권한을 **읽기 및 쓰기**로 변경
5. ⚙️ 톱니바퀴 메뉴 → **하위 항목에 적용**

#### 터미널에서 설정
```bash
# 특정 폴더에 전체 권한 부여
chmod -R 777 ~/Public/공유폴더

# 소유자 변경
sudo chown -R 사용자명:staff ~/Public/공유폴더
```

### 4.4 사용자 그룹 확인

현재 사용자가 속한 그룹 확인:
```bash
groups
# 또는
id 사용자명
```

macOS 사용자는 기본적으로 `staff` 그룹에 속함

## 5. 특정 파일 복사 실패

### 5.1 증상
- 일반 파일(png, txt 등)은 복사 가능
- 특정 파일(.pem 등)만 복사 실패
- 파일 생성/수정/삭제는 가능하나 복사만 실패

### 5.2 원인
**Windows 파일의 읽기 전용 속성**

SMB를 통해 읽기 전용 파일 전송 시 권한 충돌 발생

### 5.3 해결

#### 단일 파일
1. Windows에서 파일 우클릭 → **속성**
2. **읽기 전용** 체크 해제
3. 확인 후 복사 재시도

#### 여러 파일 일괄 처리
Windows 명령 프롬프트:
```cmd
attrib -r 경로\*.pem
```

## 추가 팁

### 네트워크 드라이브 연결
자주 사용하는 경우 드라이브 문자 할당:
1. Windows 파일 탐색기에서 macOS 폴더 접속
2. 폴더 우클릭 → **네트워크 드라이브 연결**
3. 드라이브 문자 선택 (예: Z:)
4. "로그인할 때 다시 연결" 체크

### 대안: Python HTTP 서버
일회성 파일 전송이 필요한 경우:

macOS:
```bash
cd /공유할/폴더
python3 -m http.server 8000
```

Windows 브라우저:
```
http://macOS_IP:8000
```

### IP 주소 종류
- **외부 IP (공인 IP)**: `curl ifconfig.me`로 확인, 인터넷상의 주소
- **내부 IP (사설 IP)**: 로컬 네트워크 내 주소, 파일 공유에 사용

같은 Wi-Fi를 사용해도 각 기기는 다른 내부 IP를 가짐

## 참고사항

### 보안
- API 키, 인증서 등 민감한 파일은 클라우드 업로드 지양
- 로컬 네트워크 파일 공유 또는 암호화된 채널 사용 권장

### 문제 지속 시
1. 양쪽 시스템 재시작
2. SMB 서비스 재시작 (macOS):
   ```bash
   sudo launchctl stop com.apple.smbd
   sudo launchctl start com.apple.smbd
   ```
3. Windows 자격 증명 관리자에서 관련 항목 삭제 후 재연결
